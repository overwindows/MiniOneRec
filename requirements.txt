# Flash Linear Attention (Qwen3.5 GatedDeltaNet hybrid backbone)
# Qwen3_5's linear-attention (GatedDeltaNet) layers have a fast fused-kernel
# path that transformers gates on BOTH fla AND causal-conv1d being importable
# (is_fast_path_available = all(causal_conv1d_fn, causal_conv1d_update,
# chunk_gated_delta_rule, fused_recurrent_gated_delta_rule)). Without both it
# silently falls back to a slow torch path (~10x slower eval/forward).
#
# NOTE: both are intentionally NOT installed here so they can never abort the
# transformers install. causal-conv1d has NO prebuilt wheel for our
# torch 2.6.0/cu124 stack (GitHub releases only ship cu11 torch2.6 wheels and
# cu13 torch>=2.7 wheels), so pip attempts a source build that fails with a
# CUDA-mismatch error. If causal-conv1d were in this file, `pip install -r
# requirements.txt` would ABORT mid-way, transformers would never install, and
# the eval would crash on `import transformers`. fla + causal-conv1d are instead
# installed in scripts/setup_multi_node.sh as a separate best-effort, non-fatal
# step AFTER the requirements install, so the eval always runs (on the slow path
# at minimum) and delivers AUCs.
PyYAML==6.0.1
requests==2.32.3
